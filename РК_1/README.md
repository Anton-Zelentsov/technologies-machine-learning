# Рубежный контроль №1

**Тема:** Технологии разведочного анализа и обработки данных
**Вариант:** 9 — задача №2, набор данных №1 (Iris, `sklearn.datasets.load_iris`)

Ссылка на задание: https://github.com/ugapanyuk/courses_current/wiki/TMO_RK_1

## Задание

Для заданного набора данных провести обработку пропусков в данных для одного категориального
и одного количественного признака. Какие способы обработки пропусков в данных для категориальных
и количественных признаков Вы использовали? Какие признаки Вы будете использовать для дальнейшего
построения моделей машинного обучения и почему?

## Подготовка данных

В Iris нет категориальных признаков и пропусков, поэтому по примечанию к заданию они созданы
искусственно:

- `sepal_width_cat` — категориальный признак из `sepal_width` (terciles: узкая / средняя / широкая);
- пропуски: 15 значений (10 %) в `petal_length`, 18 значений (12 %) в `sepal_width_cat`
  (random_state = 42, результат воспроизводим).

## Результаты

Обработка пропусков количественного признака `petal_length` (сравнение с истинными значениями):

| Способ | MAE, см | RMSE, см |
|---|---|---|
| Среднее | 1,590 | 1,765 |
| Медиана | 1,480 | 1,850 |
| KNN (k = 5) | **0,188** | **0,240** |

Категориальный признак `sepal_width_cat`: заполнение модой (38,9 % верно восстановленных категорий)
и замена отдельной категорией «неизвестно».

Связь признаков с классом (корреляционное отношение η): `petal_length` — 0,94,
`petal_width` — 0,93, `sepal_length` — 0,62, `sepal_width` — 0,40.
