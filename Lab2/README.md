# Лабораторная работа №2. Обработка пропусков, кодирование категориальных признаков, масштабирование данных

Датасет: **Titanic** (Kaggle, соревнование [Titanic - Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic/data)).

## Задание

По методичке курса ТМО (лаба 2 — Missing/Encoding/Scaling):
- выбрать датасет с категориальными признаками и пропусками в данных;
- решить задачи: обработка пропусков, кодирование категориальных признаков, масштабирование данных.

Ссылка на постановку задания: https://github.com/ugapanyuk/courses_current/wiki/LAB_TMO__MISSING

## Содержимое

- `data/titanic.csv` — исходные данные (891 наблюдение, 12 столбцов).
- `Lab2.ipynb` — основной ноутбук с решением (выполнен, все ячейки с выводом).
- `Lab2.html` — экспорт ноутбука в HTML.
- `Lab2.py` — код ноутбука в виде обычного Python-скрипта.
- `Отчет лаба2.docx` — оформленный отчёт (титульный лист, описание задания, текст программы, экранные формы).
- `requirements.txt` — зависимости для воспроизведения.

## Как запустить

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook Lab2.ipynb
```

## Краткое содержание ноутбука

1. Текстовое описание датасета Titanic.
2. Основные характеристики: размер, типы, доля пропусков по столбцам, категориальные/числовые признаки.
3. Обработка пропусков: `Embarked` — мода, `Age` — медиана по группам `Pclass`+`Sex`, `Cabin` → признак `Deck` с категорией `"Unknown"` вместо удаления.
4. Кодирование категориальных признаков: Label Encoding (`Sex`), One-Hot Encoding (`Embarked`, `Deck`), `Pclass` оставлен как порядковый числовой признак.
5. Масштабирование: сравнение `StandardScaler` и `MinMaxScaler` для числовых признаков (`Age`, `Fare`, `SibSp`, `Parch`).
6. Итоговый полностью числовой датасет без пропусков, готовый для обучения модели.
