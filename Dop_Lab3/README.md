# Лабораторная работа. Обучение без учителя: кластеризация и понижение размерности

Датасет: **Wine** (Kaggle, [tawfikelmetwally/wine-dataset](https://www.kaggle.com/datasets/tawfikelmetwally/wine-dataset)), 178 образцов, 13 признаков, 3 сорта.
Постановка: https://github.com/ugapanyuk/courses_current/wiki/LAB_TMO_CLUSTER

Методы: PCA (D2), t-SNE (D3); кластеризация K-Means, Agglomerative, DBSCAN, GMM; метрики: силуэт, ARI, AMI, гомогенность, полнота, V-мера.

- `data/wine.csv` — данные (178 × 14)
- `Lab_Cluster.ipynb` / `Lab_Cluster.html` / `Lab_Cluster.py` — решение (ноутбук выполнен)
- `screenshots/` — скриншоты ячеек ноутбука
- `Отчет кластеризация.docx` — отчёт (титульный лист, задание, текст программы, экранные формы, выводы)
- `build_nb.py`, `build_report.py` — генерация ноутбука и отчёта
