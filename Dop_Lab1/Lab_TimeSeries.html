Задание:

  5. Визуализировать тестовую выборку и каждый из прогнозов.

def adf_report(series, name):
    stat, p = adfuller(series.dropna())[:2]
    print(f"{name:<34} ADF = {stat:7.3f}   p-value = {p:.4f}   ->",
          "стационарен" if p < 0.05 else "нестационарен")

log_ts = np.log(ts)
adf_report(ts, "Исходный ряд")
adf_report(log_ts, "log")
adf_report(log_ts.diff().dropna(), "log, разность (d=1)")
adf_report(log_ts.diff().diff(12).dropna(), "log, разности (d=1, D=1, s=12)")

fig, axes = plt.subplots(1, 2, figsize=(12, 3.5))
d_ts = log_ts.diff().diff(12).dropna()
plot_acf(d_ts, lags=36, ax=axes[0])
plot_pacf(d_ts, lags=36, ax=axes[1])
plt.tight_layout()
plt.show()

Наблюдения. В ряду есть возрастающий тренд и годовая сезонность (период 12). Амплитуда сезонных колебаний растёт вместе с уровнем ряда, то есть сезонность мультипликативная. Исходный ряд нестационарен (ADF, p > 0.05). Логарифмирование делает сезонность аддитивной и стабилизирует дисперсию, а разности (d=1, D=1, s=12) приводят ряд к стационарному виду. Поэтому все модели строятся для log(y), а прогнозы переводятся обратно через exp и сравниваются в исходных единицах (тыс. пассажиров).

4. Прогнозирование¶

Для методов символьной регрессии и МГУА ряд превращается в задачу регрессии: по 12 предыдущим значениям (lags = 12) предсказывается следующее. Прогноз на 24 месяца строится рекурсивно — каждое предсказание добавляется в окно для следующего шага. В матрице признаков x1 — значение 12 месяцев назад, x12 — предыдущий месяц.

In [7]:
LAGS = 12
forecasts = {}

X_lag, y_lag = time_series_transformation(log_train, LAGS)

def recursive_forecast(model, steps=H, lags=LAGS):
    window = list(log_train[-lags:])
    out = []
    for _ in range(steps):
        nxt = float(model.predict(np.array([window[-lags:]]))[0])
        out.append(nxt)
        window.append(nxt)
    return pd.Series(np.exp(out), index=test.index)

print("Обучающих примеров:", X_lag.shape[0], "| признаков:", X_lag.shape[1])

6. Оценка качества прогноза¶

Используются метрики: MAE (средняя абсолютная ошибка, тыс. пассажиров), RMSE (корень из среднеквадратичной ошибки, сильнее штрафует крупные промахи) и MAPE (средняя абсолютная процентная ошибка, не зависит от масштаба). Модели сравниваются в исходных единицах.

In [14]:
def metrics(y_true, y_pred):
    err = y_true.values - y_pred.values
    return {"MAE": np.mean(np.abs(err)),
            "RMSE": np.sqrt(np.mean(err ** 2)),
            "MAPE, %": np.mean(np.abs(err / y_true.values)) * 100}

results = pd.DataFrame({name: metrics(test, fc) for name, fc in forecasts.items()}).T.round(2)
display(results.sort_values("RMSE"))

Лучший метод по RMSE на тестовой выборке: МГУА COMBI (RMSE = 15.28, MAPE = 2.80 %)
  • Ряд Air Passengers имеет тренд и мультипликативную сезонность (период 12), поэтому все модели строились для log(y).
  • Ряд разделён на обучающую (120 мес.) и тестовую (24 мес.) части; прогноз строился сразу на весь тестовый горизонт.
  • Построены прогнозы SARIMA, символьной регрессией (gplearn) и методами МГУА COMBI и MIA (gmdh); качество оценено по MAE, RMSE и MAPE.
  • Лучшими оказались COMBI (RMSE 15.3, MAPE 2.8 %) и символьная регрессия (RMSE 16.9, MAPE 3.0 %). Обе модели по сути одинаковы: значение 12 месяцев назад плюс постоянный прирост в логарифмах, то есть сезонный наивный прогноз с ростом. Символьная регрессия записала это правило как X0 + 0.121, COMBI — как 0.978*x1 + 0.2495.
  • Нелинейная MIA хуже линейной COMBI (RMSE 36.2): при рекурсивном прогнозе на 24 шага ошибка накапливается, а нелинейный полином её усиливает.
  • SARIMA(0,1,1)(0,1,1)12 показала самую большую ошибку (RMSE 43.1, MAPE 8.5 %): модель хорошо описывает обучающую часть, но на тесте занижает рост пассажиропотока.
  • Результаты МГУА сильно зависят от test_size: у COMBI RMSE меняется от 15.3 до 41.3, у MIA — от 29.3 до 174.6. Значение 0.3 выбрано уже после просмотра этой проверки, то есть по тестовой выборке, поэтому оценка для МГУА оптимистична. Тестовая выборка содержит всего 24 точки, так что сравнение методов следует считать ориентировочным.
